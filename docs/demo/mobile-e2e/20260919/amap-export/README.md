1. 在已完成行程的“行程概览”展开“整趟地点导入高德”，说明即将向高德发送地点数据。
2. 经用户确认后创建一次，页面出现“打开高德 App”和“复制地图链接”。
3. 点击打开高德 App，展示名为 JourneyGo 武汉旅行的地图与地点标记。
4. 点击右侧“列表”，展示 9 月 20 日至 24 日五条日期行程。

- 当前车站等兜底地点可能追加在当天列表后面，例如首日汉口站排在餐厅之后；不能把导出地点顺序宣称为完全还原交通时间轴。
- 整图缩放较小时标注重叠明显，展示时优先使用日期列表和单日详情。
